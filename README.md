# Self-Correcting AI Code Assistant

An AI that writes code, runs it, reads the error, and fixes it automatically.

## Features
- Autonomous write → run → fix loop
- Docker sandboxed execution
- Supports Python, Java, C++
- Root-cause error explanation
- Multiple retry strategies
- Code quality checks (linting)
- Conversation memory
- GitHub PR integration

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- AI: Claude API (Anthropic)
- Execution: Docker
- DB: SQLite
